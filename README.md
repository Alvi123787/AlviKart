# ShoppyKart 🛒

ShoppyKart is a simple **E-commerce web application** designed as a practice project to learn **full-stack development** using **React (Vite)** for the frontend and **Express (Node.js)** for the backend.

## 🚀 Features
- Browse products
- Add to cart
- Manage cart items (update, delete, adjust quantity)
- Session-based cart storage
- Basic product management with Express backend

## 🛠️ Tech Stack
- **Frontend:** React (Vite), Axios, Tailwind CSS
- **Backend:** Express.js, Node.js
- **Database:** MongoDB (Mongoose) *(planned)*
- **Version Control:** Git & GitHub

## 🎯 Purpose
This project is created for learning and practicing:
- Git & GitHub workflow
- Full-stack (MERN) development
- Project structure and best practices
- Basic E-commerce logic (cart, products, sessions)
